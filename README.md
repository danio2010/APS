# Zawartość repozytorium
Repozytorium zawiera pliki przygotowane na zajęcia z uczniami szkół średnich na WMiI UMK. Są to głównie zajęcia w ramach projektu APS (Akademia Przyszłego Studenta).

## index.html
Strona repozytorium zawsze dotyczy najbardziej bieżących zajęć.

## RRZ_lab
Zajęcia "Równania różniczkowe dla myślących laików". Dostępna wersja .html z widgetami JS lub notatnik .ipynb do samodzielnej pracy. Uruchomienie widgetów w pliku wymaga pobrania modułu z folderu `tools`.


## Folder `tools`
Zawiera pomocnicze pliki.
